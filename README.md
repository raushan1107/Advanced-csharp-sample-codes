# Advanced C# Sample Code

C# training samples, one project per topic: data types, arrays, collections, OOP, functions, loops and iterators, delegates, LINQ, exceptions, ADO.NET, DLR (with Python), XML and JSON, security, design patterns and WPF.

## What's inside

- `ArrayLearning/`, `CollectionsLearning/`, `OOPsLearning/`, `LINQLearning/`, `DelegatesLearning/` … — one console project per topic
- `WpfAppLearning/`, `WpfApp_1/`, `TestWPF/` — WPF samples
- `DesignPatternsDemo/`, `SecurityLearning/`, `XMLandJSONProcessing/`
- `Exercises/` — practice

## How to use

Open a topic folder and `dotnet run`, or open the project in Visual Studio.
